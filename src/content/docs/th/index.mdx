## คอร์สนี้ทำงานยังไง

<CardGrid>
  <Card title="เข้าใจ model ก่อน แล้วค่อยดู manifest" icon="rocket">
    ทุกหัวข้อเริ่มจาก model — reconciliation loop, Pod, Service, scheduler — พอเข้าใจแล้วพฤติกรรมของ Kubernetes จะกลายเป็นกลไกที่คุณเข้าใจ ไม่ใช่ YAML ที่ copy-paste ตามกัน
  </Card>
  <Card title="verify กับ API group ปัจจุบัน" icon="random">
    เขียนบน API group ที่ stable และใช้งานจริงใน production ทุกวันนี้ — `apps/v1`, `batch/v1`, `networking.k8s.io/v1`, `autoscaling/v2`, `policy/v1` — และตรวจสอบกับ official docs ผ่าน context7
  </Card>
  <Card title="เน้น guarantee ไม่ใช่แค่ YAML" icon="approve-check">
    ไม่ใช่แค่ "นี่คือ Deployment" แต่เป็น "rolling update การันตีอะไรจริง ๆ และตรงไหนที่ readiness probe หรือ PodDisruptionBudget ที่ขาดไปยังทำให้พังได้" คุณจะ reason เรื่อง cluster ได้อย่างมั่นใจ
  </Card>
  <Card title="ไดอะแกรมที่อธิบายได้" icon="puzzle">
    control plane, reconciliation loop, การ route ของ Service และ scheduling pipeline เป็นไดอะแกรม Mermaid ที่รองรับธีม สองภาษา (English / ไทย) พร้อมบันทึกความคืบหน้า quiz
  </Card>
</CardGrid>
